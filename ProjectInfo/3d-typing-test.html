⌨️ 3D Typing Test

Platform: WebGL / Unity
Date: June 2025
Status: Live

Project Overview

3D Typing Test is a lightweight, browser-playable Unity WebGL game that turns a simple typing exercise into a fun, gamified challenge. Players select a paragraph and race against a one-minute timer while letters react visually in a 3D scene as they type.

The project focuses on tight input handling, clean UI/UX, and instant browser playability with no downloads or installs required.

Key Features

  • Selectable Paragraphs: Multiple text samples to keep each run fresh
  • 60-Second Timed Challenge: Fast, replayable typing sessions
  • Floating 3D Alphabet: Letters animate in 3D space as you type
  • Live WPM & Accuracy Tracking: Real-time feedback on performance
  • Instant Browser Play: No install, runs directly via WebGL

Technical Stack

Unity Engine
WebGL
C#
TextMeshPro
UI Toolkit

How It Works

1. Choose a Paragraph: Pick from a set of preloaded text samples.

2. Start Typing: A 60-second timer begins as soon as you type the first character.

3. Watch the Feedback: 3D letters animate and react to correct/incorrect input.

4. Get Your Score: View your final words-per-minute and accuracy at the end.
